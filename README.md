## The word

**Situationship** — home Wi-Fi is a situationship: sometimes it's there,
sometimes it vanishes, and it never commits. Funny at once, true to how
home Wi-Fi actually behaves, and it works perfectly as a network name.

## How it works

`main.py` (Python 3, standard library only, deterministic, no network)
writes exactly that one word to `/output/entry.txt` — 13 characters,
no trailing newline.
